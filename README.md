# Dquests
An Android app that helps you farm Discord quests completely automatically, locally, and for free, without complicated setup or intermediaries, with easy login, and super lightweight (under 1MB). Includes support for selecting and claiming Hyperesquad badge (even if Discord Hypesquad test has been removed) in 3s, along with RPC, and is open source!

## Development Notes 
This application's code is built on Java 7. Modifying and recompiling it yourself might be a nightmare, but you are allowed to, as long as you adhere to the [GPLv3 license](https://github.com/MinhSangGDVN/dquests/blob/main/LICENSE) of the project!

Create a new issue if you encounter a bug. I'm not sure about pull requests, but if you genuinely want to contribute to the project, they might still be approved... if they work!
